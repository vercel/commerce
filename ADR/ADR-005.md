# ADR 005: Strict Isolation of Database ORMs to Server Components

## Context
With the adoption of the Next.js App Router, we have distinct boundaries between React Server Components (RSC) and Client Components. We have seen instances of developers accidentally importing our database ORM into Client Components, which exposes our schema to the browser and causes build failures.

## Decision
1. **Server-Side Only:** The `PrismaClient` (or any database connection instance) MUST strictly be invoked inside Server Components, Server Actions, or Route Handlers.
2. **Client Component Prohibition:** Any file marked with the `"use client"` directive at the top is strictly forbidden from importing the database ORM directly. 
3. **Data Passing:** If a Client Component needs database information, the Server Component must fetch the data and pass it down to the Client Component as serializable props, or the Client Component must trigger a Server Action.
